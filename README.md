# One App Lite

그룹웨어 **결재 작성**(야근 · 휴가 · 지출결의서)과 **Jira 티켓 보고**를 한 앱에서 처리하는 데스크톱 도구입니다. Windows · macOS.

### ⬇️ 다운로드

**[👉 최신 버전 받기](../../releases/latest)**

| 내 PC | 받을 파일 |
|-------|-----------|
| Windows | `OneAppLite-win32-x64-*.zip` |
| Mac (M1 이상) | `OneAppLite-darwin-arm64-*.zip` |

---

## 🪟 Windows 설치

1. zip 을 풀고 **폴더째** 원하는 위치로 옮깁니다 (예: `C:\Users\내이름\OneAppLite`)
   - ⚠️ `OneAppLite.exe` **하나만 빼내면 실행되지 않습니다** — 폴더 전체가 앱입니다
2. 폴더 안의 **`OneAppLite.exe`** 실행
3. *"Windows의 PC 보호"* 경고가 뜨면 → **추가 정보** → **실행**
   - 사내 배포용 미서명 앱이라 나오는 경고이며, 한 번 허용하면 다시 묻지 않습니다
4. 자주 쓴다면 `OneAppLite.exe` 우클릭 → **바로 가기 만들기** → 바탕화면으로

## 🍎 Mac 설치

1. zip 을 풀고 **`OneAppLite.app`** 을 **응용 프로그램** 폴더로 옮깁니다
2. 처음 열면 *"확인되지 않은 개발자"* 또는 *"손상되었기 때문에 열 수 없습니다"* 가 뜹니다.
   **터미널**에 아래 한 줄을 붙여넣고 실행하세요 (인터넷에서 받은 앱에 붙는 검역 표시를 떼는 명령입니다)

   ```bash
   xattr -dr com.apple.quarantine /Applications/OneAppLite.app
   ```

3. 다시 앱을 엽니다. 그래도 막히면 **시스템 설정 → 개인정보 보호 및 보안** 아래쪽의
   *"확인 없이 열기"* 를 누르세요

## ⚙️ 처음 한 번 설정

첫 실행이면 **환경설정** 화면이 먼저 열립니다.

| 항목 | 설명 |
|------|------|
| **사번(ID) · 비밀번호** | 그룹웨어(gw.forbiz.co.kr) 로그인 계정 |
| **결재 소속** | 야근 결재 근무자 표의 '소속' 칸과 휴가신청서 제목에 그대로 들어갑니다 (예: `FE챕터 플랫폼기술부문`) — **비우면 야근·휴가 결재를 시작할 수 없습니다** |
| **Jira 주소 · 이메일 · API 토큰** | 티켓 보고를 쓸 때만. 토큰은 [Atlassian API tokens](https://id.atlassian.com/manage-profile/security/api-tokens) 에서 발급 |

> 🔒 비밀번호와 토큰은 **각자 PC 의 OS 보안 저장소**(Windows DPAPI · macOS 키체인)로 암호화해 저장됩니다. 서버로 보내지 않고, 만든 사람도 볼 수 없습니다.

## 📝 결재

1. 상단 **[결재]** → 종류(야근 · 휴가 · 지출결의서)를 고르고 폼을 채운 뒤 **[작성 시작]**
2. 자동화 창이 떠서 항목이 채워지는 것이 보입니다 — **끝날 때까지 건드리지 마세요**
3. 작성이 끝나면 그 창이 그대로 남습니다 → **직접 [상신]** 을 누르세요
   (지출결의서는 파일 첨부 후 **[결재상신]**)

> ⚠️ 앱은 **작성만** 합니다. 상신은 내용을 확인한 뒤 사용자가 직접 누르는 구조입니다.
> 올라간 문서는 완료 화면의 **[전자결재 상신함 열기]** 로 확인할 수 있습니다.

## 🎫 티켓 보고

1. 상단 **[티켓 보고]** → **프로젝트** 선택 → **기간**(월 / 직접 / 전체)과 **기준**(갱신일 · 생성일 · 해결일) → **[조회]**
   - 조회 조건은 저장되어 다음에 열 때 자동으로 다시 조회됩니다
2. **상태 · 담당자 · 레이블 · 유형** 필터와 검색창으로 좁히고, 체크박스로 원하는 행만 고릅니다
3. **[N건 복사]** → 보고서에 붙여넣기

**복사 형식은 바꿀 수 있습니다.** 기본값은 `SSB-111 티켓명` 이고, 템플릿 칸 옆 **`(i)`** 를 누르면 쓸 수 있는 자리표시자가 설명·실제 값과 함께 펼쳐집니다.

```
{key} {summary} {status} {type} {assignee} {reporter} {priority}
{labels} {project} {parent} {parentSummary} {url} {created} {resolved} {updated}
탭 = \t · 줄바꿈 = \n
```

프리셋도 있습니다 — 번호만 / 티켓명만 / 번호 티켓명 / 번호 티켓명 (상태) / **탭 구분(엑셀·표에 바로 붙이기)** / 링크만.

## 🔄 업데이트

새 버전이 나오면 앱을 열었을 때 **상단에 알림 배너**가 뜹니다. **[받기]** 를 누르면 이 페이지가 열립니다.
(환경설정 화면 아래쪽 **[업데이트 확인]** 으로 직접 확인할 수도 있습니다.)

> 💾 **설정은 그대로 유지됩니다.** 사번·비밀번호·결재 소속·Jira 토큰·티켓 보고 조건은 앱 폴더가 아니라
> 사용자 프로필(`%APPDATA%\OneAppLite` · `~/Library/Application Support/OneAppLite`)에 저장되므로,
> 앱을 통째로 지웠다 새로 깔아도 남아 있습니다.

### 🪟 Windows 업데이트

1. **앱을 종료합니다** — 실행 중이면 `OneAppLite.exe` 가 잠겨 교체에 실패합니다
2. 기존 폴더를 **지우고** 새 zip 을 **같은 위치**에 풉니다
   - 바탕화면 바로가기를 쓴다면 경로가 같아야 링크가 안 깨집니다
   - 덮어쓰기(폴더 병합)도 대개 동작하지만, 지우고 새로 푸는 쪽이 확실합니다
3. `OneAppLite.exe` 실행

### 🍎 Mac 업데이트

1. **앱을 종료**하고 `/Applications/OneAppLite.app` 을 새 것으로 교체합니다 (Finder 가 물으면 **교체**)
2. ⚠️ **아래 명령을 다시 실행합니다** — 새로 받은 zip 에는 검역 표시가 **다시** 붙습니다

   ```bash
   xattr -dr com.apple.quarantine /Applications/OneAppLite.app
   ```

   빼먹으면 *"손상되었기 때문에 열 수 없습니다"* 가 뜹니다. 처음 설치할 때와 같은 명령입니다.
3. 앱 실행

## 🆘 문제가 생기면

| 증상 | 확인할 것 |
|------|-----------|
| 결재 작성이 로그인에서 멈춤 | 환경설정의 사번·비밀번호. 그룹웨어 비밀번호를 최근에 바꿨다면 다시 저장 |
| "결재 소속을 설정하세요" | 환경설정 → 결재 소속을 채우고 저장 |
| 티켓 보고가 비어 있음 | Jira 주소 · 이메일 · **API 토큰** 세 가지가 모두 있어야 동작합니다 |
| 앱이 안 켜짐 (Windows) | 폴더째 옮겼는지 확인 — exe 하나만 있으면 실행되지 않습니다 |
| 앱이 안 켜짐 (Mac) | 위 `xattr` 명령을 실행했는지 확인 |

그 외 문제나 요청은 만든 사람에게 알려주세요.
